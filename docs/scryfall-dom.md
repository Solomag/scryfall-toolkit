# Scryfall DOM contract

Every Scryfall class name the dark theme depends on, and where it lives.

**Why this file exists.** The theme paints over Scryfall's styles by naming their
markup. That is a real dependency: Scryfall can rename a class at any time, and the
symptom is a page that comes out partly unthemed. When that happens, this is the one
place to look — not 358 rules scattered across a stylesheet.

A test reads every part of the theme and fails if it uses a class name that is not listed
here. Adding a rule that reaches for a new class means writing down what that class is.

The **Part** column names the file a dependency is written in. That is the point of the
split: one class name, one file to open, instead of a few hundred rules to search.

Generated by `node tools/dom-contract.cjs`. Do not edit by hand.

**Not included:** this project's own `stk-*` markers, which theme.js sets and which
Scryfall knows nothing about.
